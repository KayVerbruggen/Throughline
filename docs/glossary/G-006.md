---
id: G-006
title: Handle
aliases:
  - component handle
created: "2026-07-14"
---

The camelCase form of a component's title, used to reference its state variables inside guard expressions — the title "Application Store" becomes the handle `applicationStore`, so a guard reads `applicationStore.dirty == false`. Because the handle is derived from the title, renaming a component changes it (see [[D-004]]).
