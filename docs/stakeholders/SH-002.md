An automated agent (such as the one that wrote this model) that reads and writes the project through its plain-text files. It drafts artifacts, and — the headline use case — reverse-engineers an existing codebase into a first-cut Throughline model. It needs the on-disk format, the id conventions and the consistency rules to be legible and forgiving, because it authors files directly rather than through the UI.
