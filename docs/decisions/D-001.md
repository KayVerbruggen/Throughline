In the system-structure model, facing a stored connection graph would drift out of sync with the flows that justify it, we decided to derive every component-to-component connection from flow adjacency, and store none and not to let users draw and store connections directly to achieve a single source of truth, so structure can never contradict behaviour, accepting that a static dependency (module A imports B) can't be shown unless a flow places them adjacent.
