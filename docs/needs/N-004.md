Most systems are modelled long after they are built. The agent needs to take an existing codebase and produce a first-cut Throughline project — stakeholders, needs, use cases, requirements, components and flows — recovering the design intent that the code only implies. This is the hardest thing the model is asked to represent, and the biggest test of whether the data model is expressive enough.
