WHEN a running token reaches a step that calls another use case's flow, the Throughline tool shall run the called flow's steps against the same valuation and resume the caller after the call returns.

A call is executed, not skipped: the callee's guards and effects read and write the
same component variables the caller does, so composing flows composes one system
state. Calls may nest; a call nested past a fixed depth degrades to a pass-through
with a note, which is what stops a recursive flow from running forever.
