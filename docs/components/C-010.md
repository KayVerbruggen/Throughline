The right-hand editing surface (`detail/DetailPanel.tsx` and the per-kind bodies). It renders the selected artifact's fields, lets the user edit them, and forwards each change to the Application Store. Note: it keeps its own kind-to-list lookup, so every new artifact kind must be registered here as well as in the store.
