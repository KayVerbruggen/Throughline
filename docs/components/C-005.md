The behaviour-expression pipeline (`src/model/expr`): tokenizer, precedence-climbing parser, resolver and type-checker. It turns a guard string such as `applicationStore.dirty == false` into a checked AST, resolving component references by their camelCase handle and validating them against the components' declared variables. Evaluation (the simulator) is deferred to a later stage.
