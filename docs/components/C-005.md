The behaviour-expression pipeline (`src/model/expr`): tokenizer, precedence-climbing parser, resolver, type-checker and evaluator. It turns a guard string such as `applicationStore.dirty == false` into a checked AST, resolving component references by their camelCase handle and validating them against the components' declared variables, then evaluates it against a runtime valuation so the Behaviour Engine can run a flow. It also type-checks activity effects (`head.name := value`).
