Everything that touches the filesystem: the Rust backend (`storage.rs`) that does raw directory and file I/O across the per-kind folders, and the TypeScript serialisation code (`storage/serialize.ts`, `frontmatter.ts`) that maps each file's YAML frontmatter and markdown body to and from a typed artifact. Parsing is deliberately defensive; serialisation is deterministic so round-tripping leaves a minimal diff.
