The flow editor (`views/BehaviorView.tsx`). The left pane renders a use case's flow as an ordered list of activity steps with alternate paths shown inline, supports drag-to-reorder, offers token-aware autocomplete for authoring guards and activity effects (validated live through the Expression Engine), and sets who initiates each step. The right pane shows the flow's two derived diagrams via an Activity/Sequence toggle: the activity diagram can be **run** — a token steps through it, applying effects and evaluating guards with a live valuation panel — and the sequence diagram's messages can be reassigned to a different sender.
