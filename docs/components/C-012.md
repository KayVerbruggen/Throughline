The traceability grid (`views/TraceabilityView.tsx`). It lays the spine out as columns — needs, use cases, requirements, tests — with each artifact linked to the ones it traces to, so a reviewer can scan for a need with no use case or a use case with no requirement. It reads the reverse-trace links computed by the Model Core; it stores nothing of its own.
