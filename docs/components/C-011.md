The behaviour derivations and interpreter (`src/model/activityDiagram.ts`, `sequenceDiagram.ts`, `interpret.ts`, `actors.ts`). From a single flow it derives two diagrams — the per-flow **activity diagram** (control-flow nodes and guarded branches) and the per-flow **sequence diagram** (actor and component lifelines with hand-off messages and alt/loop fragments) — and it can **execute** the activity diagram: a single token walks it carrying a valuation seeded from component variables, applying each activity's effects and evaluating branch guards through the Expression Engine. Actors on the sequence diagram resolve to Stakeholders by id or title, so human lifelines are traceable. Pure and deterministic, like the Structure Deriver beside it.
