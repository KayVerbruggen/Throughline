The behaviour derivations and interpreter (`src/model/activityDiagram.ts`, `sequenceDiagram.ts`, `interpret.ts`, `actors.ts`). From a single flow it derives two diagrams — the per-flow **activity diagram** (control-flow nodes and guarded branches) and the per-flow **sequence diagram** (actor and component lifelines with hand-off messages and alt/loop fragments) — and it can **execute** the activity diagram: a single token walks it carrying a valuation seeded from component variables, applying each activity's effects and evaluating branch guards through the Expression Engine. A step that calls another use case's flow is executed too — the interpreter keeps a **call stack**, descending into the callee and running it against the *same* valuation, then resuming the caller at the call step. Variables belong to components, not flows, so a call needs no scoping; a depth limit stops a recursive call. Actors on the sequence diagram resolve to Stakeholders by id or title, so human lifelines are traceable. Pure and deterministic, like the Structure Deriver beside it.
