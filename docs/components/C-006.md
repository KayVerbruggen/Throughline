Where the core consistency rule lives (`behavior.ts`, `hierarchy.ts`, `layout.ts`). It never stores connections: it scans every flow for activities that run back-to-back, maps them to the components that own them, and emits the undirected connection graph. It also resolves the stored parent hierarchy and lays the whole thing out as either a tidy tree or nested blocks.
