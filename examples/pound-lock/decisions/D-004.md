In where the operator stands and what they reach, facing a single operator should run a passage without walking the quay to work each gate, we decided to expose the complete passage cycle from one console that issues high-level commands to the interlock controller and not to keep local per-gate control panels the operator moves between to achieve one person can run a full cycle without leaving their station, accepting that the console must never actuate a gate directly, or it would bypass the interlock.
