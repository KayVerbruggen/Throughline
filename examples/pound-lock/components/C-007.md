The green/red signs on each side of the lock that tell skippers when it is safe to enter the chamber. Driven entirely by the interlock controller so the signals can never contradict the gate state.

Showing red at one reach is not an action of its own — it is what happens when the other reach is permitted, or when neither is. So there are only three things this component can be asked to do, plus the manual override the keeper uses when testing.
